# Xelaris

**Software a medida para negocios reales.**

En Xelaris desarrollamos sistemas de gestión, plataformas web y herramientas de facturación para pymes y comercios.

## 🚀 Qué hacemos

- **Sistemas de punto de venta:** ventas, stock, caja, reportes y factura electrónica (ARCA).
- **Plataformas de reservas:** turnos online para canchas de fútbol y pádel.
- **Facturación:** sistemas de facturación integrados.
- **Gestión de obras:** seguimiento y control de proyectos.
